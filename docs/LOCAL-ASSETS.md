# 可选本地素材包

公开代码和默认四个场景不依赖付费小镇素材。可选素材包为 **Cartoon Town – Low Poly Assets**，作者 **ricimi**。素材包不随本项目提供，请自行查找并取得合法使用授权，再导入本地素材包。导入确认不代表本项目验证了你的购买或授权。

## 在游戏中导入

1. 启动本机游戏，进入「布置房间 → 素材包」。
2. 点「检查本机工具」，按提示准备缺少的工具。
3. 选择自己已有的 `.unitypackage` 文件，确认已取得合法使用授权，点「导入素材包」。文件只交给本机游戏服务处理。
4. 等待包检查、模型转换、作者场景还原、地面准备、缩略图与完整性检查。可以关闭窗口，任务仍会继续；重开窗口可看进度。
5. 完成后点「返回家具目录」继续布置。素材会自动启用，不自动刷新页面；已有布置草稿会保留。

只支持已验证的 **1.0** 包内容指纹。其他版本，包括1.5，尚未验证；即便文件名写着1.0，内容或重打包方式不同也可能被拒绝。未知包、转换失败或检查不通过，不会替换现有素材或重置存档。单次上传最多32MiB。

## 本机工具

- **Blender**：macOS自动查找应用目录，否则使用PATH中的 `blender`。可以设置 `TOWN_BLENDER_PATH` 为可执行文件路径。
- **Python + UnityPy 1.25.4**：使用独立虚拟环境，不需要全局安装。已存在 `.cache/unity-parser-venv/bin/python` 时自动使用；也可设置 `TOWN_PYTHON_PATH`。
- **Chrome/Chromium + Playwright**：Playwright属于项目开发依赖。macOS自动查找Chrome，其他系统可使用Playwright已有的Chromium；设置 `TOWN_CHROMIUM_PATH` 可指定浏览器可执行文件。浏览器使用临时隔离profile。

例如，你可自行在项目目录准备Python虚拟环境：

```sh
python3 -m venv .cache/unity-parser-venv
.cache/unity-parser-venv/bin/python -m pip install UnityPy==1.25.4
```

Windows可把 `TOWN_PYTHON_PATH` 指向该环境的 `Scripts/python.exe`。程序不自动安装工具、不下载付费素材，也不运行素材包内的C#、编辑器插件或命令。

转换需要本机CPU、磁盘和浏览器渲染能力；耗时因电脑而异。每个转换阶段有15分钟上限，页面显示当前阶段，不承诺所有机器都能在相同时间完成。

## 导入后的世界

目录解锁213种模型、中文名称和真实缩略图。作者原布局的小镇、海边可从便利店进入：新世界优先将小镇接到便利店北侧，海边使用其他空闲可达出口。没有便利店、出口被占用/阻挡或场景数量已满时，目录仍能使用，窗口会说明场景未接入的原因。不会移动已有家具来腾位置。

已有作者场景、已编辑或已删除的摆设均保留，不会重新铺回默认物件。已由本功能添加后又被删除的场景也不会自动重建。手工放入的地形块是景观装饰；作者原场景使用共享地面数据支持行走、台阶、桥面和游泳。

## 存储、恢复与公开构建

- 当前本地库：`.cache/town-assets/`。
- 隔离任务、上传文件、部分输出、受限长度的日志及旧库备份：`.cache/.town-import-jobs/<任务ID>/`。
- 个人存档：`data/game.sqlite`。服务在成功启用时写入必要的本地目录与作者地面元数据，以便文件缺失时显示占位和地面回退。
- 一个服务只运行一个导入任务；重复服务也会检查任务锁。保留最多5个任务目录，达到上限会提示你手工检查并清理旧任务。不要在导入进行中删除锁或任务目录。确认不再需要恢复旧库后再删除其备份。
- 启用时保留旧库，失败会回滚。中断后启动会根据数据库提交记录恢复尚未提交的目录切换；服务正常关闭会停止子进程并阻止迟到启用。

开发启动和生产 `npm start` 均会发现本机已导入的库。`npm run build` 不复制它；Git与发布检查排除原包、模型、贴图、缩略图及原作者布局。不要把 `.cache` 或个人数据库打包给其他用户。

HTTP导入仅接受拥有者网页会话，并校验CSRF和同源请求；普通MCP访问令牌不能导入或指定本机路径。素材目录、缩略图和模型仍受已有访问控制保护。


## 随项目提供的 Polyfork 精选库

- `resources/polyfork/` 随公开仓库提供，共 146 个 GLB 及从这些 GLB 本机渲染的 WebP 缩略图。模型、缩略图与署名约 22 MiB。逐条署名见 [CREDITS.md](../resources/polyfork/CREDITS.md)，分发许可见 [LICENSE.md](../resources/polyfork/LICENSE.md)。
- 没有本地素材清单时，服务会加载这份精选库。选了本地库以后，默认场景已经摆进去的精选模型仍由项目提供。精选库由服务按需提供，Vite 不会把它复制到网页构建目录。
- `.cache/town-assets/` 保存本机全量库，或你在游戏里导入的其他素材。整个目录及导入备份都在 Git 忽略范围内。克隆项目后可用精选库开始游戏，再按需添加自己的素材。

## 白泽伙伴

白泽伙伴和野生白泽共用公开模型 `resources/character/models/baize.glb`，随仓库和桌面版提供。原有本机 `companions/baize.glb` 仍可覆盖内置模型。

进入游戏后，伙伴白泽会随大肥鱼探索。走过森林高草可能遇到野生白泽。对战时点击敌人打开技能菜单，分别为大肥鱼和白泽选择招式。[森林与对战玩法](../README.md#森林与回合制对战)
