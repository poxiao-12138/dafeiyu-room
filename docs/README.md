## 系统分工

- 游戏：保存世界，执行已接受的动作，检查碰撞、建设规则、控制权和授权；网页展示结果。
- 外部智能体：决定去哪里、做什么，以及如何回应用户。
- DSH 等宿主：开放工具、管理智能体会话、唤醒、活动预算和任务续跑。
- QQ：当前陪伴玩法的聊天入口；游戏不提供另一套聊天页面，也不合成语音。

关闭网页不等于停止世界服务。后端运行时，已接受的有限动作可以继续；智能体的下一次思考由宿主触发。游戏不承担让模型无限自主思考的调度。
